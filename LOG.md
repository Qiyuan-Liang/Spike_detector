# Spike Detector Change Log

Current version: `3.5.41`

- 2026-05-28: Added `AGENTS.md` repository memory file.
- 2026-05-28: Updated threshold/template detection filter semantics so each cutoff side can be disabled independently with a value of `0` or below. Added CS low-cut controls, changed CS detection filter defaults to off (`CS_LOW_CUT_HZ = 0`, `CS_HIGH_CUT_HZ = 0`), and kept SS defaults at `50-700 Hz`. Updated GUI controls, saved settings sync, reset defaults, detection execution, preview, and CS filter visualization paths to use the new CS low/high cutoff settings.
- 2026-05-29: Corrected threshold filter defaults after user clarification: CS uses restored default low/high cutoffs of `0/150 Hz`, and SS defaults to unfiltered `0/0 Hz`. Added explicit detection-control synchronization before saving GUI settings so current CS/SS filter values are saved and later restored by the load-settings path.
- 2026-05-30: Hardened detection session iteration so non-empty session paths cannot be skipped when `session_names` is empty or shorter than `sessions`. Rebuilt adaptive wavelet denoising around complex Morlet CWT, per-frequency normalization, PCA elbow feature selection, Ward/silhouette clustering up to 20 clusters, per-cluster threshold masks, per-cluster reconstruction, per-cluster event PC1 attenuation, and no global amplitude rescaling. Updated denoising preview labels and tips for the new workflow.
- 2026-05-30: Patched shared `src/spike_detector/utils/processing.py` detection functions to accept `cs_low_cut` and use the same `0=off` high/low filter semantics as the GUI, fixing runtime detection errors from the imported processing functions. Tuned denoising defaults for AOD traces with 500-1000 Hz shot noise (`f_max=1000 Hz`, `n_freqs=72`, `threshold_sigma=1.5`, `attenuation_min=0.25`, `moving_cycles=1.0`) and separated input/denoised preview traces into stacked panels.
- 2026-05-30: Fixed Advanced Settings application for SS blank/min-distance by synchronizing hidden main-window spin boxes after the dialog writes `params`, preventing later main-window sync/save from restoring stale values. Updated defaults to baseline correction window `30 ms`, SS threshold `2.5 x MAD`, and centered SS blank `12 ms`; removed the previous extra pre-CS offset so SS blanking is centered on each CS peak.
- 2026-05-30: Released GUI version `3.5.1`. Added trace-fingerprinted denoise caching for main trace rendering, detection reuse, and detection preview; switched the main plot redraw to idle refresh for smoother slider interaction. Changed denoising to feed SS detection by default while leaving CS detection on the original corrected trace unless enabled in Advanced Settings. Kept Detection Viewer raw panels on the original processed raw trace, kept Spike Statistics waveform/SNR/FWHM source on original corrected raw traces, and moved long change history from `AGENTS.md` to this file.
- 2026-05-30: Released GUI version `3.5.2`. Improved denoising preview readability by removing the upper trace x-axis, using separate robust y-scaling for input and denoised traces, and adding a concise setting diagnosis to the preview status line. Added file path display to the main info panel, auto-scrolled post-detection info to the overall CS/SS summary and final availability message, and changed the default SS blank window to `15 ms`.
- 2026-06-30: Released GUI version `3.5.3`. Tuned spike-statistics FWHM measurement so CS FWHM is measured from the CS detection trace instead of the raw waveform source used for SNR/waveform display, preventing detected CS events from being dropped simply because raw high-frequency substructure narrows the half-height crossing. Replaced the strict sign-change FWHM finder with a robust interpolated half-height crossing plus `peak_widths` fallback in both GUI and shared processing utilities.
- 2026-06-30: Released GUI version `3.5.4`. Changed default CS minimum FWHM to `4 ms`, replaced Spike Statistics ISI panels and text with instantaneous spike-rate distributions, and added `Analysis/compare.ipynb` for two-folder spike-set comparison with configurable group names, colors, plot style, dF/F, SNR, FWHM, waveform overlays, and automatic SVG/PNG export.
